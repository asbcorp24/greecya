# Чек-лист публикации

- [ ] Указать production-домен и включить HTTPS.
- [ ] Установить `APP_ENV=production`, `APP_DEBUG=false`.
- [ ] Заменить демонстрационные цены, тренеров и расписание.
- [ ] Загрузить реальные фотографии комплекса.
- [ ] Заменить тестовые пароли администратора и менеджера.
- [ ] Указать реквизиты организации в оферте и политике обработки данных.
- [ ] Подключить интернет-эквайринг и проверить webhook оплаты.
- [ ] Настроить SMS/email-уведомления о записи.
- [ ] Настроить cron: `php artisan schedule:run`.
- [ ] Настроить резервное копирование базы и файлов.
- [ ] Проверить права на `storage` и `bootstrap/cache`.
- [ ] Провести тестовую запись, отмену, оплату и погашение билета.

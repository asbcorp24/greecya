# Комплекс «Греция»

Laravel 9 + Bootstrap 5: публичный сайт бассейна и SPA, онлайн-запись, продажи, CRM, контент и личный кабинет клиента.

## Возможности

- онлайн-запись и управление расписанием;
- CRM для клиентов, лидов, заказов, оплат и посещений;
- билеты, абонементы и сертификаты с QR-кодом;
- личный кабинет с записями, сертификатами и планами тренировок;
- новости, фотогалерея, тренеры и слайдер главной;
- отдельный раздел контактов, режима работы, соцсетей и реквизитов;
- SEO по маршрутам: title, description, keywords, Open Graph, canonical, robots и JSON-LD;
- автоматические `/sitemap.xml` и `/robots.txt`;
- полный идемпотентный набор сидеров и демонстрационных SVG-изображений.

## Установка

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

## Обновление существующего проекта

```bash
git checkout feature/settings-seo-seeders
git pull origin feature/settings-seo-seeders
php artisan migrate
php artisan db:seed
php artisan storage:link
php artisan optimize:clear
```

`php artisan db:seed` можно запускать повторно: демонстрационные записи обновляются по стабильным ключам и не дублируются.

## Разделы CRM

- `/admin/settings` — название, тексты, логотип, favicon и промо;
- `/admin/settings/contacts` — телефоны, email, адрес, режим работы, карта, соцсети и реквизиты;
- `/admin/seo` — SEO-настройки публичных страниц;
- `/admin/news` — новости;
- `/admin/gallery` — фотогалерея;
- `/admin/slides` — слайдер;
- `/admin/trainers` — тренеры;
- `/admin/certificates` — сертификаты;
- `/admin/training-plans` — планы тренировок.

## Что заполняют сидеры

- настройки сайта и контактов;
- SEO для публичных и служебных страниц;
- администратор, менеджер и тестовый клиент;
- услуги, тренеры и расписание на 21 день;
- билеты, абонементы и сертификаты;
- слайды, новости, альбомы и фотографии;
- клиенты, лиды, записи, заказы и оплаты;
- посещения, планы тренировок, упражнения и прогресс.

## Тестовые учётные записи

- администратор: `admin@greecya.local` / `ChangeMe123!`
- менеджер: `manager@greecya.local` / `ChangeMe123!`
- клиент: `client@greecya.local` / `ChangeMe123!`

Перед production замените тестовые пароли, демонстрационные реквизиты, цены и расписание. Laravel 9 больше не получает штатные обновления безопасности, поэтому для боевого запуска рекомендуется запланировать обновление фреймворка.

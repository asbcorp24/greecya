# Комплекс «Греция» — бассейн и SPA

Готовый MVP на **Laravel 9 + Bootstrap 5** для бассейна и SPA-комплекса в Васильево: публичный сайт, подбор свободного времени, онлайн-запись, каталог билетов и абонементов, заказы и CRM для сотрудников.

## Что реализовано

### Публичная часть
- адаптивная главная страница в средиземноморском стиле;
- описание бассейна 25 м, морской воды 32°C и SPA-услуг;
- акция со словом «БАССЕЙН» и подарком в соляной комнате;
- выбор услуги, даты и реально свободного слота;
- защита от переполнения слота через транзакцию и блокировку записи;
- форма обратного звонка, которая создаёт лид в CRM;
- каталог разовых билетов, абонементов и сертификатов;
- создание заказа и заготовка для платёжного провайдера;
- страницы политики конфиденциальности и оферты.

### CRM
- роли `admin` и `manager`;
- сводная панель с записями, лидами, клиентами и выручкой;
- управление статусами записей и оплатой;
- календарные слоты услуг и тренеров;
- клиентская база с количеством записей и заказов;
- воронка входящих лидов;
- продажи билетов и абонементов;
- автоматическая генерация электронного кода билета после отметки оплаты;
- управление товарами и их видимостью на сайте;
- таблицы платежей и посещений для дальнейшего развития.

## Установка

```bash
git clone https://github.com/asbcorp24/greecya.git
cd greecya
git checkout feature/mvp-pool-spa-crm
composer install
cp .env.example .env
php artisan key:generate
```

Создайте базу MySQL `greecya`, укажите доступы в `.env`, затем выполните:

```bash
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

Сайт: `http://127.0.0.1:8000`  
CRM: `http://127.0.0.1:8000/login`

## Важные настройки перед публикацией

1. Заменить демонстрационные цены, имена тренеров и расписание в CRM/сидере.
2. Добавить реальные фотографии комплекса.
3. Заполнить реквизиты юридического лица в политике и оферте, согласовать документы с юристом.
4. Подключить интернет-эквайринг. Сейчас `PAYMENT_PROVIDER=manual`; структуры `orders`, `payments`, `order_items` и статусы уже готовы. Для ЮKassa предусмотрены переменные `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`, но боевой API намеренно не активирован без реквизитов.
5. Настроить отправку SMS/email и резервное копирование базы.
6. На production установить `APP_ENV=production`, `APP_DEBUG=false`, HTTPS и безопасные cookies.

## Дизайн

Палитра сочетает морской синий, светлую бирюзу, тёплый песочный и коралловый акцент. Интерфейс ориентирован на главное действие — подобрать свободное время — и построен mobile-first.

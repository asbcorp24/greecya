# Комплекс «Греция»

Laravel 9 + Bootstrap 5: публичный сайт бассейна и SPA, онлайн-запись, продажи, расширенная Pool CRM, контент и личный кабинет клиента.

## Как сайт связан с CRM

Сайт и CRM — одно Laravel-приложение и одна база данных. Отдельной синхронизации между ними нет.

- услуги и расписание на сайте берутся из `services` и `schedule_slots`, которыми управляет CRM;
- онлайн-запись создаёт/обновляет клиента и создаёт `booking` в CRM;
- занятые места сразу учитываются в слоте и загрузке бассейна;
- каталог сайта использует `products`;
- оплаченный товар, связанный с `membership_plans`, автоматически создаёт активное `membership` клиента;
- подарочный товар после оплаты создаёт сертификат и QR-код;
- новости, фотогалерея, слайды и тренеры выводятся на сайт из тех же таблиц, которые редактируются в CRM;
- телефоны, адрес, режим работы, реквизиты и соцсети берутся из `site_settings`;
- SEO на публичных страницах берётся из `seo_pages`;
- личный кабинет читает те же записи, членства, сертификаты, карты доступа, меддопуски, посещения и планы тренировок, которые видит персонал в CRM.

Таким образом, действие на сайте сразу становится операцией CRM, а изменение расписания, цены, контента или контактов в CRM сразу отражается на сайте.

## Основные возможности Pool CRM

- зоны бассейна и дорожки, загрузка сеансов и лист ожидания;
- членства, пакеты посещений, заморозки и автопродление;
- депозитные и бонусные счета, уровни лояльности;
- QR/NFC/штрихкодовые карты, СКУД, медицинские допуски и шкафчики;
- кассы, смены, платежи, продажи, возвраты, расходы и инкассация;
- склад и движения товаров/расходников;
- графики сотрудников, правила начисления и зарплата;
- CRM-задачи, коммуникации, рассылки, корпоративные клиенты и договоры;
- журнал параметров воды и технических работ;
- отчёты по выручке, посещаемости, загрузке, услугам и тренерам;
- новости, фотогалерея, тренеры, слайдер, контакты и SEO;
- личный кабинет клиента.

## Роли

- `admin` — полный доступ ко всем разделам;
- `manager` — операционная CRM, продажи, бассейн, расписание, контент и управление;
- `accountant` — заказы, оплаты, касса, клиенты, склад, персонал/зарплата и отчёты; нет доступа к бассейну, СКУД, контенту сайта, настройкам и SEO;
- `customer` — личный кабинет клиента.

## Установка

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed
php artisan storage:link
php artisan serve
```

## Обновление существующего проекта

```bash
git checkout feature/pool-crm-suite
git pull origin feature/pool-crm-suite
php artisan migrate
php artisan db:seed
php artisan storage:link
php artisan optimize:clear
```

`php artisan db:seed` можно запускать повторно: демонстрационные записи обновляются по стабильным ключам и не дублируются.

## Основные разделы CRM

- `/admin/pool` — бассейн, дорожки, параметры воды и обслуживание;
- `/admin/access` — СКУД, проход и шкафчики;
- `/admin/schedule` — расписание;
- `/admin/bookings` — записи;
- `/admin/memberships` — членства и пакеты;
- `/admin/finance` — касса и платежи;
- `/admin/inventory` — склад;
- `/admin/staff` — графики и зарплата;
- `/admin/crm-plus` — задачи, коммуникации, рассылки, организации и договоры;
- `/admin/reports` — отчёты;
- `/admin/settings` — настройки сайта;
- `/admin/settings/contacts` — контакты и реквизиты;
- `/admin/seo` — SEO;
- `/admin/news`, `/admin/gallery`, `/admin/slides`, `/admin/trainers` — контент сайта.

## Тестовые учётные записи

- администратор: `admin@greecya.local` / `ChangeMe123!`
- менеджер: `manager@greecya.local` / `ChangeMe123!`
- бухгалтер: `accountant@greecya.local` / `ChangeMe123!`
- клиент: `client@greecya.local` / `ChangeMe123!`

Перед production замените тестовые пароли, демонстрационные реквизиты, цены и расписание. Laravel 9 больше не получает штатные обновления безопасности, поэтому для боевого запуска рекомендуется запланировать обновление фреймворка.
